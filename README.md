Entry for the make.fun bounty **Ridiculous at First Glance, Real by the Second**. `main.py` runs a local tournament over ten original one-sentence startup pitches, scoring each on the judge brief — how genuinely bizarre the idea is, whether the business logic survives a second look, how cleanly the sentence lands as a pitch, and how concrete and vivid the writing is — and writes the winning pitch (164 characters) to `/output/entry.txt`. The pick is deterministic: every run writes byte-identical output.

The winning pitch: an app that turns your partner's snoring into nightly subtitles, so sleep-deprived spouses pay monthly to finally read what the snoring meant.

## Run it

```sh
python3 main.py
```
